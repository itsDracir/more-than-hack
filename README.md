# The goats — More than a Hack 2027, Phase 1: Ball Possession

Labels every frame of the BAR-ATH tactical video as `H` / `A` / `D` / `X`. No model is trained and
no labelled data is used: per-frame evidence from the tracking and the Smart Tagging, decoded into
clean intervals with Viterbi. Approach, assets, parameters, possession rules, results and
limitations: [TECHNICAL.md](TECHNICAL.md).

## Install

Python 3.12.10.

```bash
pip install -r requirements-lock.txt
```

## Data

The match data is **not** in this repository and must never be committed (it is not
redistributable). Unpack the official bundle so that `data/tactical/BAR-ATH_tactical_atd.txt`
exists, or point `MTAH_DATA_DIR` at the folder that contains `tactical/`.

## Reproduce the submission

```bash
python -m jupyter nbconvert --to notebook --execute solution/01_preprocessing.ipynb --output-dir data/processed
python solution/run.py --name "The goats"
```

The notebook is the only step that reads the raw data. It writes the per-frame feature table and
the set-piece intervals to `data/processed/` (git-ignored). `run.py` labels every frame, writes
`evaluation/results/The goats.csv` and checks it with the official validator. There is no
randomness: the same data gives the same file, byte for byte.

## Tests

```bash
python -m unittest discover -s solution/tests -t .
```

41 tests, on synthetic data generated by code; they never read the match data.

## Layout

| path | what |
|---|---|
| `solution/01_preprocessing.ipynb` | features: ball position, nearest player of each team, team mean speeds, Smart Tagging |
| `solution/run.py` | command line: features in, submission file out |
| `solution/labeling.py` | order of decisions: outside the halves `X`, dead ball `D`, team `H` / `A` |
| `solution/deadball.py` | is the ball in play? |
| `solution/teams.py` | which team has it? |
| `solution/viterbi.py` | best label sequence given per-frame evidence and a cost per change |
| `solution/params.py` | every parameter, with its reason |
| `games.py`, `starter/{baseline,load_atd,load_smart_tagging}.py`, `evaluation/possession_metrics.py` | unchanged from the official challenge repository (© Metrica Sports, MIT, see `LICENSE`) |
